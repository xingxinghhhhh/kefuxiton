# 说明

本文档只用于本地开发和离线评测，不代表任何真实企业制度，不得自动发布。

## 1. 忘记账号密码怎么办？

### 问题

忘记本人账号密码后应该怎么办？

### 答案

不要在聊天中提供密码、验证码、Token 或其他凭证。应使用企业批准的密码重置入口；入口不可用时转人工服务台。

### 适用条件

- 用户正在处理本人账号。
- 用户身份可以通过批准方式确认。

### 例外

- 涉及他人账号或无法完成身份确认时转人工。

## 2. 如何申请办公系统访问权限？

### 问题

如何申请某个办公系统的访问权限？

### 答案

通过批准的申请流程提交，由有权限的审批人确认。客服 Agent 只能解释已发布步骤，不能直接授予、修改或绕过权限。

### 适用条件

- 用户说明系统和业务用途。

### 例外

- 管理员权限、生产权限或权限争议转人工。

## 3. 办公系统无法打开怎么办？

### 问题

办公系统无法打开或页面报错怎么办？

### 答案

确认访问地址来自批准来源，检查网络并重试。问题持续时提供脱敏错误描述并转人工。

### 适用条件

- 故障属于常规访问问题，且未提交凭证或敏感截图。

### 例外

- 多人同时故障、生产系统或安全告警转人工。
