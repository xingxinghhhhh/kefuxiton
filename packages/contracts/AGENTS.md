# 接口契约与共享类型规则

本规则继承仓库根目录 `AGENTS.md`，适用于 `packages/contracts`。

## 单一真源

- API 契约以 OpenAPI 或明确的共享 schema 为单一真源。
- 前后端不得各自手写一份同名请求/响应类型。
- 领域内部类型不自动暴露成公共 API 类型，只暴露稳定、脱敏、必要的字段。
- 契约变更必须说明兼容性、迁移顺序和客户端影响。

## 错误与状态

统一定义错误码、HTTP 状态映射、用户可见文案键、可重试标记、是否需要转人工、是否写入审计。

AI 相关状态至少区分：回答成功、知识未命中、引用不足、模型超时、检索失败、工具失败、需要补充信息、转人工中、人工已接入。

## 版本规则

- 新增字段优先保持向后兼容。
- 删除、改名、改变枚举语义必须走弃用周期。
- 不把数据库内部 ID、异常堆栈或 provider 原始错误直接暴露为公共契约。
- 生成客户端后必须运行类型检查和接口契约测试。
