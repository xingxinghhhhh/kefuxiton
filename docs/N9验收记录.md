# N9 验收记录：客户消息反馈与审计闭环

## 节点范围

- 公开 AI（含安全拒答）和人工客服消息支持固定反馈。
- 客户会话隔离、一次性记录、幂等重放、冲突保护和刷新恢复。
- 创建、重放、冲突审计；审计不含消息正文、Token 或隐藏上下文。
- 不影响 AI、检索、转人工、知识发布和业务写操作。

## 验收标准

- [x] `helpful` / `not_helpful` 之外的值被拒绝。
- [x] 客户消息、系统消息、待转人工消息、缺失消息和跨会话消息被拒绝。
- [x] 同键同值返回 `replayed`；同消息换键同值返回 `already_recorded`。
- [x] 同消息不同值返回 `FEEDBACK_CONFLICT`；幂等键跨消息复用返回 `IDEMPOTENCY_KEY_REUSED`。
- [x] 刷新消息历史后恢复反馈状态，重复按钮不可用。
- [x] 反馈审计只含固定标识字段和值。
