# N11 验收记录：发布前运行配置与安全预检闭环

## 节点范围

- 新增内部统一配置校验模块和 `pnpm preflight`。
- API 启动前 fail-closed；Web 公开 API 配置校验；production 禁止测试能力。
- 配置错误只返回安全错误码与字段名，不输出秘密或客户数据。
- 不新增数据库迁移、公共业务 API、第三方依赖、真实生产能力或外部调用。

## 验收标准

- [x] 缺失或非法配置被明确拒绝。
- [x] DATABASE_URL、WEB_ORIGIN 和 NEXT_PUBLIC_API_BASE_URL 只做结构校验并安全报错。
- [x] production 拒绝测试 Staff、测试 Token、测试 Staff 标识和知识发布开关。
- [x] API 配置失败时不监听端口；未配置正式身份时保持 deny-by-default。
- [x] Web 不接受带凭证的公开 API URL，production 构建要求 HTTPS。
- [x] preflight 不迁移、不写数据库、不发布知识、不访问外部系统。
- [x] N1–N10 业务闭环和权限边界回归通过。

## 变更清单

- `packages/config`：运行配置类型、校验、错误码、脱敏格式化和 preflight 结果。
- API：启动配置门、Staff auth mode 读取和知识发布开关读取。
- Web：Next 配置校验和 config workspace 构建顺序。
- `scripts/preflight.mjs`、配置矩阵单测、启动 smoke、N11 固定评测。
- ADR、运行手册和本验收记录。

## 验证结果

- `pnpm preflight`：通过（完整 synthetic/test 配置）。
- `pnpm verify`：通过（24 个基础契约、8 个角色契约）。
- `pnpm lint`：通过。
- `pnpm typecheck`：通过。
- `pnpm test:unit`：通过（26/26，含配置矩阵单测和 Web smoke）。
- `pnpm test:integration`：通过（12/12，真实 PostgreSQL）。
- `pnpm test:api-smoke`：通过（生产 API smoke + 配置启动 smoke）。
- `pnpm test:e2e`：通过（3/3，隔离 API/Web 端口）。
- `pnpm test:eval`：通过（N2–N11 全部固定评测）。
- `pnpm build`：通过。
- 配置启动 smoke：production 测试身份在监听前拒绝，输出不含测试密码或 Token。
- `pnpm preflight` 退出码约定：0=通过，1=配置拒绝，2=预检程序自身异常；程序异常也只输出安全错误码和字段名。
- 已知非阻断警告：Nest 构建产物存在 Node 模块类型提示；Next 报告未检测到 ESLint Next 插件，均未导致门禁失败。
