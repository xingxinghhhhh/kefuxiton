# N12 验收记录：合成发布演练与回滚证据

## 节点目标

在本地隔离 PostgreSQL schema 中完成一次生产形态发布演练、测试 harness 回归和 N11 兼容回滚读取校验；不接触真实客户数据，不执行真实生产部署。

## 变更清单

- `scripts/run-release-rehearsal.mjs`：统一编排输入、schema、迁移、构建、生产 smoke、测试 harness、摘要、回滚和清理。
- `scripts/run-isolated-e2e.mjs`：支持 external schema，避免重复迁移和删除主演练数据。
- `tests/smoke/api-production.mjs`：支持 external schema、可配置端口和显式 test/deny 身份模式。
- `tests/fixtures/release-rehearsal-published.md`：仅供本地演练的已发布知识。
- `tests/evals/n12-release-rehearsal.json`、`tests/evals/run-n12-eval.mjs`：固定边界评测。
- `docs/adr/0010-N12合成发布演练与回滚.md`、本记录和运行手册：记录操作边界和证据格式。

## 验收标准

- [x] 生成唯一且可验证的 rehearsal schema。
- [x] 迁移只执行一次，测试 harness 不创建或删除 schema。
- [x] production 禁止 test Staff、test token 和知识发布。
- [x] production smoke 通过健康、引用、拒答、注入阻断、凭证拒绝和接管创建。
- [x] test API smoke 与 E2E 在同一 schema 上通过。
- [x] 回滚前后计数、固定状态和关系摘要一致，既有会话/反馈/接管仍可读。
- [x] 子进程全部终止，唯一 schema 被清理；清理失败可见且返回 5。

## 验证结果

最终演练：`pnpm test:release-rehearsal`，退出码 0。迁移 8/8；production smoke、test API smoke、E2E 3/3、N11 基线 `91942d9` 校验和 rollback validation 全部通过。回滚前后摘要计数均为：Conversation 7、Message 24、KnowledgeVersion 1、KnowledgeChunk 1、HandoffRequest 4、AuditEvent 26、MessageFeedback 5、InternalNote 2、ConversationTag 2；关系摘要保持一致。输出仅记录阶段、计数和截断 SHA-256 引用，未记录连接串、Token、客户正文或完整日志。

统一门禁：`pnpm verify`、`pnpm lint`、`pnpm typecheck`、`pnpm test:unit`（26/26）、`pnpm test:integration`（12/12）、`pnpm test:api-smoke`、`pnpm test:e2e`（3/3）、`pnpm test:eval`（N2–N12）、`pnpm build` 均退出码 0。
