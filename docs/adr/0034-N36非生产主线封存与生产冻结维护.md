# ADR-0034：N36 非生产主线封存与生产冻结维护

## 状态

已接受；N36 只维护并验证现有 synthetic/local_eval/rehearsal 证据，不构成生产准入。

## 决策

N36 复用 N34 的 `n34.v1` 最终冻结 Manifest，建立只读冻结回归。评测在内存中生成固定字段顺序的 `FreezeCheckSummary`，不写新 Manifest、不入库、不覆盖 N34 摘要。

回归验证 N29–N35 证据链、N34 `manifestDigest`、三种 readiness 状态、production 六个 blocker 顺序以及 N35 三态评测。生产继续 `NOT_READY`，local_eval 和 rehearsal 继续保持可验证状态。

## 范围与不做事项

仅新增 N36 评测、验收/ADR 文档、运行手册条目和 root package 的评测入口。禁止修改 N34 Manifest、N29–N35 原有评测、生产 API/Web、数据库、权限、readiness、配置和依赖。不得接入真实模型、企业知识、Staff Identity、部署、外部系统或生产授权。

## 安全与输出

评测成功输出严格为固定 `caseId/status/reasonCode`；子进程输出不转发。冻结摘要只包含 schemaVersion、digest 是否匹配、节点顺序/数量、readiness、冻结状态、授权状态、真实资料状态和 synthetic/productionIntegration 标志，不包含 Manifest 正文、路径、日志、连接串、Token、客户数据或堆栈。

## 回滚

回滚点为 `3ea75be`。失败时只删除 N36 新增评测、文档、运行手册条目和 package 脚本接入，不执行 `reset`、`clean`，不触碰 N34 Manifest 或生产代码。
