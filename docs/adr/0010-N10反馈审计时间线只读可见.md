# ADR-0010：N10 Staff 反馈审计时间线只读可见

## 状态

按 ChatGPT N10 最终开发决策进入实现。

## 决策

复用 N7 的 Staff 时间线，不新增 API、写操作、数据表或迁移。反馈事件只有在 `AuditEvent.handoffRequestId` 明确等于目标接管请求、且 `conversationId` 同时匹配时才投影。`handoffRequestId` 为 `null` 的 N9 历史反馈保持不变并 fail-closed 隐藏；不按时间、最近请求或会话数量推断归属。

人工客服消息通过 `OperatorReply.handoffRequestId` 建立反馈审计关联。没有明确接管关联的 AI 消息反馈不进入 Staff 时间线。客户反馈仍可正常写入客户反馈表和客户自己的消息历史。

允许投影的 action 只有 `message_feedback_created`、`message_feedback_replayed` 和 `message_feedback_conflict`。结果固定映射为 `created -> succeeded`、`replayed -> replayed`、`conflict -> rejected`。公共时间线增加可空 `feedbackValue`，仅允许 `helpful` / `not_helpful`；客户 `actorRef` 固定为 `null`，`subjectRef` 仅作为截断的消息 opaque 标识。

时间线投影严格校验 action、outcome、feedback value、subject type 和 metadata；未知值或不完整 metadata fail-closed，不透传原始 metadata、feedbackId、消息正文、客户身份、Token 或隐藏上下文。Staff 继续使用 `handoff:read` 和 `conversation:read` 权限，客户 Bearer 不可访问。

## 不做事项

不增加反馈管理写接口、过滤搜索、统计报表、通知、外部系统、AI/检索调用或客户反馈修改能力。

## 回滚与降级

回滚目标为 N9 提交 `1013e47`。不删除反馈、消息或审计数据；若时间线投影异常，只隐藏反馈事件展示，客户反馈写入、客户聊天、人工回复和转人工流程继续工作。
