# ADR-0038：N42 非生产客服工作台体验增强

## 状态

Accepted for non-production evaluation only. Production remains `NOT_READY`.

## 背景

现有客户 Chat 和 Staff 页面已经覆盖安全闭环，但信息层级、角色边界和状态反馈过于简略，难以观察引用、拒答、转人工、反馈与审计投影。用户要求先改善可视化体验；ChatGPT 决策将其限定为一个不扩展后端能力的 N42 垂直切片。

## 决策

采用统一的本地演示工作台布局：左侧角色导航，中间主任务区，右侧会话/权限说明。客户页面突出安全对话和服务端引用，Staff 页面突出接管队列和脱敏审计时间线。所有已有 API 调用、合同类型、客户 Token 传递方式和 Staff 权限校验保持不变。

## 约束

只使用合成或本地评测数据；不新增 API、DTO、数据库、迁移、依赖、模型、知识源或生产配置。客户页面不把会话 Token 或内部上下文放入可见 UI；Staff 页面不猜测或补齐服务端未返回的字段。N42 不能把 rehearsal 证据转化为生产授权。

## 验收与回滚

8 个固定 N42 评测场景、现有 E2E 加角色隔离覆盖和完整门禁全部通过后，节点标记 `N42_ACCEPTED`。若回滚，恢复至提交 `762e595`；不改变此前生产 blocker 和冻结状态。
