# ADR-0035：N37 非生产冻结基线定期回归

## 状态

已接受；N37 只维护 synthetic/local_eval/rehearsal 的冻结回归，不构成生产准入。

## 决策

新增只读评测入口，读取并验证 N34 `n34.v1` Manifest、N35 18 条三态评测、N36 15 条冻结评测和三种 readiness。N37 使用 N36 提交 `2b8a473` 中三个基线文件的固定 SHA-256，并同时核对当前文件摘要，防止评测内容静默漂移。

N37 不生成 Manifest、不写文件、不入库、不启动 API、不访问网络，不导入生产模块或 LangGraph runner。为验证 N36 没有因当前工作树新增 N37 文件而失真，N37 在固定提交 `2b8a473` 创建临时 detached worktree，使用 D 盘现有依赖的隔离视图，生成临时 Prisma Client，并运行未修改的 N36 evaluator；worktree、依赖视图和生成物在 `finally` 中清理。成功输出严格限制为固定 `caseId/status/reasonCode`，另允许一条 `N37-N36-BASELINE-RUN` 安全汇总；子进程原始输出不转发。

## 范围与不做事项

仅新增 N37 评测、验收/ADR 文档、运行手册条目和 root package 的 N37 入口。禁止修改 N34 Manifest、N35/N36 评测、生产 API/Web、数据库、权限、readiness、配置和依赖。不得接入真实模型、企业知识、Staff Identity、部署、外部系统或生产授权。固定基线 worktree 是唯一允许的临时资源，禁止使用当前工作树作为其可写依赖目录。

## 回滚

回滚点为 `2b8a473`。失败时只删除 N37 新增评测、文档、运行手册条目和 package 脚本接入，不执行 `reset`、`clean`，不触碰现有生产边界。
