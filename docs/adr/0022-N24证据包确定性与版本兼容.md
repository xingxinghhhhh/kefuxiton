# ADR-0022：N24 证据包确定性与版本兼容复核

## 状态

已接受。N24 是对 N23 `n23.v1 EvidenceBundle` 的离线复核节点，不新增证据格式。

## 决策

固定 N23 在相同语义输入下的确定性、输入突变隔离和版本兼容行为。`sealEvidenceBundle` 与 `verifyEvidenceBundle` API、N23 字段、固定 14 个 reason code 和 `n23.v1` 语义保持不变。

确定性要求包括：固定 N20 case 顺序、显式字段构造、canonical 紧凑 JSON、UTF-8、小写 SHA-256、对象属性插入顺序不影响结果、输入数组不被静默排序。封存结果不保留外部 envelope 或输入数组的可变引用；验证不修改调用方对象，重复验证结果一致。

版本兼容矩阵严格区分当前 `n23.v1`、未知 bundle schema、bundle source、bundle digest algorithm、envelope source、envelope digest algorithm、非法 envelope、envelope/item digest 篡改和 bundle digest 篡改。N24 不新增错误码、不接受未来版本、不做静默迁移。

## 范围与不做事项

- 只增加 LangGraph lab 的确定性/兼容/突变隔离回归测试、16 条固定评测和文档。
- 只有真实核对发现 N23 内部缺陷时，才允许做保持公开契约不变的最小修正。
- 不修改 N23 公开字段或 reason code，不新增 `n24.v1`，不改 N19–N22 契约。
- 不写文件、不入库、不接 API/Web/外部模型/网络，不重新执行 N20/N21，不读取 fixture，不创建 `MemorySaver`。

## 验证与回滚

N24 固定评测包含 16 条确定性、属性顺序、输入顺序、突变隔离、重复验证、版本/算法和篡改场景，并保留 N23 13 条评测与 N22 回归。回滚点为 `ce0367e`；只移除 N24 测试、评测、文档和必要的 N23 内部最小修正，无数据回滚。
