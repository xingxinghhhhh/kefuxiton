# ADR-0027：N29 生产准入待确认模板

## 状态

已批准的非生产决策冻结节点。

## 决策

在正式生产前置条件尚未由负责人确认前，仓库只保存一个不含真实值的结构化待确认模板。模板把七组决策记录为 `PENDING_CONFIRMATION`，并把生产状态固定为 `NOT_READY`。模板不是正式业务输入包，不是知识发布授权，不是模型或身份配置，也不是部署凭证。

模板固定记录业务输入及审批、知识来源/版本/生效时间、Agent Provider、Staff Identity、部署目标、数据保留、回滚责任与方案，以及两个待计算摘要状态。所有引用使用 `<PENDING>`；不得填写真实企业名称、人员、模型、URL、凭证、哈希、客户数据或生产系统标识。

## 不变量

- `productionReadiness` 必须是 `NOT_READY`。
- `confirmationStatus` 必须是 `PENDING_CONFIRMATION`。
- 现有 N15 readiness evaluator 不修改；production 仍返回既有阻断原因码。
- `local_eval` 和 `rehearsal` 的既有行为不改变。
- 模板不改变 `ALLOW_KNOWLEDGE_PUBLISH`，不启用正式 Staff Identity 或 Agent Provider。
- 不新增 API、Web、数据库、依赖、环境变量、生产代码或外部系统调用。

## 验证与回滚

N29 固定 15 条离线评测：模板字段/占位符 5 条、七组负责人决策待确认 7 条、生产门禁不能通过 1 条、local_eval 1 条、rehearsal 1 条。评测只输出 `caseId`、`status`、`reasonCode`，失败时不输出路径、堆栈或原始对象。

回滚点为 `fc3d7ab`。回滚只删除 N29 模板、评测和文档，不执行数据库或生产回滚。
