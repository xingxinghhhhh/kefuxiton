# ADR-0001：仓库初始化与 Codex 协作机制

- 状态：已接受
- 日期：2026-08-09
- 决策人：项目负责人和 ChatGPT 规划对话
- 执行人：主控 Codex/总工程师

## 背景

项目需要让 ChatGPT 负责规划与决策，让 Codex 负责仓库内的拆解、实现、审查和集成，同时避免多个角色无边界地修改同一工作区。

## 决策

采用一个主控 Codex、八个项目级可复用角色配置和按开发节点划分的 Git 分支。并行写入仅在任务独立时使用 worktree。所有有效决策写入仓库文档或 ADR，不能依赖聊天记录作为唯一依据。

N0 只建立协作与工程基础设施，不开始业务开发。Codex 角色并发上限设置为 4。

## 后果

主控会话保持项目全局上下文；子代理负责窄范围工作并返回摘要。并行工作需要严格的文件边界和集成步骤，但能降低上下文污染和代码互相覆盖风险。
