# ADR-0009：N9 客户消息反馈与审计闭环

## 状态

已批准进入实现（ChatGPT N9 开发决策）。

## 决策

客户只能对本人会话中的公开 AI 消息或公开人工客服消息提交一次固定反馈：`helpful`（有帮助）或 `not_helpful`（没帮助）。反馈是 synthetic/local-eval 信号，不代表正式满意度政策，也不会自动修改提示词、知识库、模型、会话状态或业务数据。

反馈接口使用会话 Bearer 凭证、消息路径参数和幂等键。数据库以 `(conversationId, messageId)` 保证每条消息最多一条反馈，以 `(conversationId, idempotencyKey)` 防止幂等键跨消息复用。冲突不覆盖原反馈。

创建、重放和冲突均在同一事务中写入脱敏审计事件；审计只记录反馈 ID、会话 ID、消息 ID 和固定值，不记录消息正文、Token、隐藏上下文或客户凭证。客户消息、系统消息、待转人工占位消息、缺失消息和跨会话消息统一拒绝。

## 不做事项

本节点不加入自由文本、评分体系、报表、通知、自动学习、知识发布、人工绩效结算或外部系统写入。

## 回滚与降级

迁移只新增表和索引，回滚目标为 N8 提交。若反馈不可用，前端隐藏或禁用反馈控件并显示明确失败，不将失败伪装为成功。
