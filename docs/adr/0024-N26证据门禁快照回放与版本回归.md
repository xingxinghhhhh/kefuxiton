# ADR-0024：N26 证据门禁快照回放与版本回归

## 状态

已批准的非生产离线实验节点。

## 决策

N26 只在测试目录建立 14 个固定、受控、内存中的 N25 输入场景。每个场景创建两组全新对象，连续调用既有 `buildEvidenceGateSnapshot`，比较九字段结果和显式字段顺序的紧凑 JSON 字节。

N26 不新增 `n26.v1`、运行时类型、生产接口或持久化。它不重新执行 N20/N21，不运行 LangGraph，不读取外部 fixture，不调用数据库、网络、模型、文件、MemorySaver、LangGraph Server 或 LangSmith。

## 固定回归

14 条回放覆盖 N25 全部场景：合法、缺失、重复、顺序、未知 case、身份不一致、bundle/envelope source、bundle/envelope algorithm、两类 digest 篡改、敏感/未知字段和 malformed/empty。另有 8 条版本与实现回归，固定当前/未知/未来 schema、source/algorithm 映射、14 个 N23 reason code、N25 exact-key 和异常 fail closed。

回放结果只允许固定场景 ID、两次 N25 九字段快照、deterministic 和 regressionStatus；不增加 caseId、时间、traceId、路径或业务正文。

## 回滚

回滚点为 `6f03aac`。只需移除 N26 测试场景、评测、脚本和文档，不涉及数据或生产配置。
