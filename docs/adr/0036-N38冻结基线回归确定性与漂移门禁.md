# ADR-0036：N38 冻结基线回归确定性与漂移门禁

## 状态

待 ChatGPT 审查；N38 只维护 synthetic/local_eval/rehearsal 的确定性回归，不构成生产准入。

## 决策

新增只读评测入口，每次从固定提交 `2b8a473` 创建独立临时本地 Git Clone，叠加当前已接受的 N37 评测文件，连续两次运行未修改的 N37 evaluator。Clone 拥有独立 Git 元数据，允许 N37 在其中创建并清理自己的内部 detached worktree。执行器只解析固定的 `caseId/status/reasonCode` 三字段，生成包含固定基线提交和 N37 事件顺序的安全摘要，并要求两次摘要字节一致；N37 内部托管的 N36 结果必须为 15/15。Clone、内部 worktree、依赖视图、Prisma 生成物和构建产物均在 `finally` 中清理，子进程原始输出不得转发。

## 范围与不做事项

仅新增 N38 评测、验收/ADR 文档、运行手册条目和 root package 的 N38 eval 接入。禁止修改 N34 Manifest、N35/N36/N37 评测契约、生产 API/Web、数据库、权限、readiness、配置和依赖。不得接入真实模型、企业知识、Staff Identity、部署、外部系统或生产授权。

## 回滚

回滚点为 `2b8a473`。失败时只删除 N38 新增评测、文档、运行手册条目和 package 脚本接入，不执行 `reset`、`clean`，不触碰既有生产边界。
