# ADR-0002：N1 单 Web Chat 会话安全闭环

- 状态：实现中
- 日期：2026-08-09
- 决策来源：ChatGPT「AI客服开发计划」对话

## 决策

首个业务节点只实现匿名会话、消息持久化、确定性 Mock Agent、共享契约和 Web Chat 演示页面。会话凭证只返回一次，服务端只保存 SHA-256 哈希；消息写入必须校验会话凭证和 active 状态。

## 明确不做

不接入真实模型、RAG、知识库、企业业务事实、登录/RBAC、多租户、人工客服、流式输出、业务工具调用、生产系统或 SQLite。

## 后续

N1 审核通过后，再由项目负责人确认首个业务领域和脱敏知识文档，才评估 N2 知识库发布与检索引用闭环。
