# ADR-0010：合成发布演练与回滚证据

## 状态

已实现，待 ChatGPT 审核；仅适用于本地 synthetic/test 数据，不代表已获准生产部署。

## 背景

N11 已建立配置预检，但仍需要一个可重复的发布前闭环，证明生产形态不会带入测试身份或知识发布能力，并证明回到 N11 兼容产物后既有会话、知识、接管、反馈和审计关系不被破坏。

## 决策

- `pnpm test:release-rehearsal` 生成唯一 `release_rehearsal_*` schema，并且只对该 schema 执行创建、迁移和清理。
- 迁移只由主演练流程执行一次；API smoke 和 E2E 以 external schema 模式复用同一数据。
- 合成知识先以 test-only 流程导入为 published；生产形态使用 `APP_ENV=production`、`STAFF_AUTH_MODE=deny`、`ALLOW_KNOWLEDGE_PUBLISH=0`，并删除测试凭证。
- 生产 smoke 覆盖健康检查、会话创建/读取、已发布知识引用、保守拒答、注入阻断、无效凭证和 Staff 拒绝；测试 harness 复用既有 API smoke 与 Playwright E2E，覆盖人工接管、回复、反馈和时间线。
- 回滚校验固定以 `91942d9` 为 N11 基线，验证当前业务源码与 Prisma 没有偏离，并在同一 schema 上比较安全摘要：各领域计数、关系 SHA-256 摘要和固定状态；不记录正文、客户原文、Token 或连接串。
- 所有子进程在 `finally` 中终止；清理失败返回固定退出码 5，禁止静默忽略。禁止 `git reset`、`git clean` 和 `prisma migrate reset`。

## 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 演练与回滚全部通过 |
| 1 | 阶段验证失败 |
| 2 | 输入或配置无效 |
| 3 | 阶段超时 |
| 4 | 子进程无法终止 |
| 5 | 自有 schema 清理失败 |

## 回滚

本节点只新增演练脚本、测试适配、合成 fixture、评测和文档，不改变业务模块、契约、Prisma 模型或迁移。因此回滚验证使用当前构建产物配合 N11 基线差异检查；若未来演练包含业务代码变更，必须改为独立临时 worktree 或已构建的 N11 产物，并重新取得决策。
