# ADR-0037：N39 冻结回归链最终封存

## 状态

审核状态：N39_ACCEPTED。N39 只封存 N34–N38 的 synthetic/local_eval/rehearsal 安全证据，不构成生产准入。

## 决策

新增 `n39.v1` 只读 Manifest，固定 N34→N35→N36→N37→N38 顺序、来源 SHA-256、评测数量、重复次数、readiness、生产 blocker 和冻结状态。N39 从固定提交 `e1b313f` 创建独立临时 Clone，仅通过子进程调用现有 N38 evaluator 一次；N38 自身负责两次 Clone、N37/N36 托管、摘要一致性和清理。N39 只解析 N38 的安全三字段输出，不转发原始日志，并在 finally 清理自己的 Clone。

## 范围与不做事项

仅新增 N39 evaluator/Manifest、验收与 ADR 文档、运行手册条目和 root package 的 N39 eval 接入。禁止修改 N34–N38 evaluator/cases、生产 API/Web、数据库、readiness、权限、依赖和锁文件。不得接入真实模型、企业知识、Staff Identity、部署或外部系统。

## 回滚

回滚点为 `e1b313f`。失败时只删除 N39 新增文件和 package 脚本接入，不执行 `reset`、`clean`，不触碰 N34–N38 或其他用户修改。
