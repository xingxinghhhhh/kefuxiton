# ADR-0029：N31 合成准入示例与生产门禁一致性回归

## 状态

Accepted for read-only synthetic consistency evaluation only.

## 决策

N31 增加一个只读回归评测，逐项对照 N30 合成示例、N29 正式准入待确认模板和现有 readiness CLI 输出。评测复用 `release:readiness`，不复制或修改准入逻辑。

固定结论必须保持：N30 仅为 `SYNTHETIC_ONLY`，N29 仍为 `PENDING_CONFIRMATION`，`local_eval` 和 `rehearsal` 可用，`production` 仍以固定顺序的六个阻断原因返回 `NOT_READY`。

## 允许修改范围

- `tests/evals/n31-synthetic-readiness-consistency.json`
- `tests/evals/run-n31-eval.mjs`
- `docs/adr/0029-N31合成准入示例与生产门禁一致性.md`
- `docs/N31-acceptance.md`
- `docs/运行手册.md`
- 根 `package.json`：仅接入 N31 evaluator

不得修改 N29/N30 模板、`packages/config`、readiness evaluator、生产代码、API、Web、数据库、依赖或锁文件。

## 回滚

回滚点为 `316e0a6`。失败时只删除 N31 新增文件和 package script 接入，不执行 reset/clean，不触碰 N29/N30 文件。
