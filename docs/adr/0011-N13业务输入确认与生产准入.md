# ADR-0011：N13 业务输入确认包与生产准入门禁

## 状态

已接受（2026-08-11）。

## 决策

业务领域、服务受众、知识来源、范围、人工接管场景和禁止动作先以版本化 JSON 输入包表达。`packages/config` 是唯一的解析、规范化和准入判定实现；状态由校验结果派生，不信任文件中的 readiness 字段。

首期只提交合成 `local_eval` 包 `config/business-readiness/synthetic-local-eval.json`。它只能得到 `LOCAL_EVAL_READY`，不能用于生产。正式业务包不得提交仓库，也不得包含姓名、电话、邮箱、客户原文或凭据。

知识正式发布前必须先通过生产准入判定，失败时在创建 Prisma 客户端和任何数据库写入之前退出。现有历史知识、N1-N12 数据和本地演练不做迁移或删除；N12 使用显式 `local_eval` 目标继续演练。

## 状态与拒绝原因

- `NOT_READY`：缺失、无效、未确认、来源未批准、时间未生效、过期、已取代、哈希不匹配、冲突或合成包生产拒绝。
- `LOCAL_EVAL_READY`：完整合成包，只允许离线/本地评测和测试数据库。
- `PRODUCTION_READY`：仅真实业务包在正式确认、来源批准和有效时间窗口内才可能得到；本仓库当前不制造这种输入。

固定原因码由配置包统一维护，CLI 只输出状态、目标、包标识、原因码和规范化哈希。

## 不在本节点

不新增 API、Prisma 表、迁移、身份系统、审批后端、通知、模型供应商、生产部署或业务写操作。
