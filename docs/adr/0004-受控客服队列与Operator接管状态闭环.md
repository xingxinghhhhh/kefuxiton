# ADR-0004：受控客服队列与 Operator 接管状态闭环

## 状态

已实施，等待 ChatGPT 节点审核。

## 决策

在 N3 客户发起人工接管请求的基础上，增加最小的内部客服队列和接管状态机：

```text
requested -> claimed -> closed
```

客服端只提供待处理请求列表、请求详情、接管和关闭；客户端显示状态并在请求存在时持续禁止 Agent 自动回复。关闭后本期仍保持自动回复抑制，避免在未明确业务决策前恢复模型行为。

## 身份与安全边界

- 通过 `StaffIdentityPort` 隔离正式身份提供方。
- 未配置正式适配器时默认拒绝 Staff API。
- 仅在显式测试模式下读取测试 Token 环境变量；Token 不进入仓库、日志、页面 URL 或测试样例。
- 客户 Bearer 凭证不能访问 Staff API；客户端不能提交操作者、状态或时间戳。
- claim/close 使用条件更新和审计事件，保证并发下只有一个操作者成功接管。

## 不在本节点范围

正式 SSO/LDAP、通知、SLA、自动分配、客服回复、内部备注、标签、报表、多租户、多渠道、语音和任何业务写操作。

## 回滚

应用可回滚到 N3 提交；保留新增字段、审计历史和人工请求数据，并暂停 Staff API。不得删除接管历史。
