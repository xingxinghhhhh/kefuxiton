# N5 验收记录：Operator 人工回复与客户可见消息闭环

## 节点目标

让当前 claimed Operator 发送一条可审计、可幂等的人工回复，客户刷新 `/chat` 后可见，且 AI 继续禁止自动回复。

## 已实现

- 新增 `POST /api/v1/staff/handoff-requests/:requestId/replies`，正文只接受受限长度的 `content` 和 `idempotencyKey`。
- 新增 `GET /api/v1/conversations/:conversationId/messages`，只返回当前 Bearer 会话的公开消息。
- 新增 `OperatorReply` 和 `Message.senderType`，人工消息保持 `role=agent` 兼容旧客户端，并标记 `human_operator`。
- 回复、关联、审计在同一事务中完成；重复幂等键返回原回复；非 claimedBy Operator、requested、closed 和客户凭证均被拒绝。
- `/staff/handoffs` 的 claimed 卡片可发送人工回复；`/chat` 刷新后显示“人工客服”消息。

## 验收结果

- claimed Operator 可发送；requested/closed/非拥有 Operator 不可发送。
- 客户可读取自己的人工消息，跨会话不能读取。
- 回复审计覆盖 `operator_reply_created` 与 `operator_reply_replayed`，不记录回复正文。
- 回复不调用 AgentPort；接管状态下不产生 AI 消息。
- N1/N2/N3/N4 行为与评测继续保留。
