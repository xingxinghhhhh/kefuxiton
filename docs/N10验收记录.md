# N10 验收记录：Staff 反馈审计只读可见闭环

## 节点范围

- 在现有 Staff 接管请求时间线中投影明确关联的反馈创建、重放和冲突事件。
- 仅展示固定反馈值、事件结果、时间和截断消息标识。
- 保持客户隔离、Staff 权限、N7 分页排序和 fail-closed 规则。
- 不新增 API、数据库迁移、写操作、统计、通知或 AI/知识链路。

## 验收标准

- [x] 人工客服消息反馈通过 `OperatorReply.handoffRequestId` 在对应接管时间线可见。

- [x] 无明确接管关联的 AI 反馈不可见。
- [x] 同时匹配 `handoffRequestId` 和 `conversationId`，不同接管请求不串入。

- [x] Staff 只看到有帮助/没帮助和截断消息标识，不看到正文、Token、feedbackId 或原始 metadata。
- [x] N1–N9 时间线、客户聊天和人工回复回归通过。
