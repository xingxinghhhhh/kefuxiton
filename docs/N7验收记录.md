# N7 验收记录：Staff 只读审计时间线

## 节点目标

在 Staff 侧按时间展示单个接管请求的已审计处理事件，帮助 Operator 复盘；仅复用 `AuditEvent`，不改变状态、不新增写操作。

## 接口

`GET /api/v1/staff/handoff-requests/:requestId/timeline?limit=50&cursor=<opaque>`

响应返回 `requestId`、`conversationId`、固定投影的 `items` 和 `nextCursor`。事件按 `occurredAt ASC, eventId ASC` 稳定排序。游标绑定 `requestId`，limit 范围为 1–100。

## 脱敏与边界

- 需要既有 `handoff:read` 和 `conversation:read` Staff 权限。
- 客户 Bearer、无效 requestId、非法/跨会话读取均拒绝。
- actor ID 只返回掩码；不返回原始 metadata、人工回复正文、内部备注正文、Token、密码、Prompt 或客户敏感信息。
- action、result、subjectType、tag 都使用固定 allowlist；未知事件或 metadata fail closed。
- 客户页面、Agent、检索、引用和模型链路不读取时间线。

## 不做事项

新增审计写入/表、编辑/删除、客户查看、通知、转派、SLA、统计、外部系统、真实身份和 AI/知识链路。

## 回滚与降级

回滚至 N6 提交 `00107ec`。时间线异常时只禁用时间线并明确报错，不返回原始审计数据；N1–N6 行为保持不变。
